# Zapfy

**O Zap da sua empresa, no automático.**

Zapfy é o CRM brasileiro que mora dentro do seu WhatsApp: centraliza conversas, qualifica leads com IA e fecha venda enquanto você dorme.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Lovable Cloud (Supabase) — auth, banco, edge functions, realtime
- Evolution API + WhatsApp Cloud API

## Desenvolvimento

```bash
bun install
bun run dev
```
